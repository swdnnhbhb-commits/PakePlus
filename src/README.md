# 地铁内涝风险评估（单站演示原型）

这是一个适用于 Windows 的轻量网页原型，采用单个 HTML 文件，无需安装开发环境或依赖包。

## 打开方式

1. 下载或解压项目文件。
2. 双击 `index.html`，用电脑上的浏览器打开。
3. 修改左侧的站点、地质环境和天气输入；结果会随之更新，也可按“重新评估”。

建议使用新版 Microsoft Edge 或 Google Chrome。天气服务需要联网；即使离线，也可以手动填写天气参数使用系统。

## 功能

- 手动录入降雨、车站埋深、出入口、周边地势、土壤透水情况、排水、防汛设施和客流。
- 可选查询城市未来 6 小时逐小时降雨，并将峰值和有雨时长载入天气输入框；查询后仍可手动修改。
- 展示可解释的参考风险分值、等级、情景趋势和简化车站示意图。
- 天气查询失败时显示原因，并保留手动评估入口。

风险分值由降雨强度、持续时间、车站埋深、出入口数量、周边地势和土壤透水性等因素加分，再由排水能力和防汛设施减分；分值区间映射到低、中、高、很高四个演示等级。每个因素对当前分值的影响会显示在结果卡片中。

## 重要使用边界

本原型面向学习、演示和方案展示。风险分值和等级由简化启发式规则生成，阈值是演示参数，不是行业标准，也未经专业验证。趋势图是假设当前降雨条件持续的情景推演，并非天气预报或水动力预测。客流疏散图是简化方向示意，没有使用真实车站图纸、实时客流或出口通行能力。请勿将结果用于实际运营决策、预警发布或应急指挥。

天气数据来自 Open-Meteo 公共地理编码和天气预报服务，仅作参考。城市级预报无法代表具体车站的局地天气。具体服务可用性取决于网络和服务提供方。
